Set up Email (SMTP)

This is the mailbox the system sends firm notices from.

  1. In cPanel open Email Accounts and create (or pick) a mailbox such as noreply@yourfirm.com.
  2. Click Connect Devices on that mailbox to see Mail Client Manual Settings.
  3. Copy the Outgoing Server value into SMTP host — usually mail.yourfirm.com.
  4. Set Port to 465. Security is chosen automatically.
  5. Enter the full address as the username, and the mailbox password.
  6. Set From email to the same address, and a From name like your firm name.
  7. Click Verify & save at the top of this page.

If verification fails, confirm the password by signing into webmail with the same address.

Set up SMS

Connect either Africa's Talking or Twilio.

  1. Create an account with Africa's Talking or Twilio.
  2. Select that company under SMS provider.
  3. For Africa's Talking, enter your username, API key, and approved sender ID.
  4. For Twilio, enter your Account SID as the username, Auth Token as the API secret, and your Twilio number as the From number.
  5. Use the international number format, for example +2547....
  6. Click Verify & save at the top of this page.

Provider trial accounts may only send to verified phone numbers.

Set up WhatsApp

Start with simple click-to-chat, then enable the API only if needed.

  1. Enter your business WhatsApp number in international format, for example +2547....
  2. Add an optional default message. This is enough for click-to-chat links.
  3. Leave WhatsApp Business API off if you only need click-to-chat.
  4. For automatic sending, enable the API and select Meta Cloud API or Twilio.
  5. For Meta, paste the access token and Phone Number ID from Meta for Developers.
  6. For Twilio, enter the token as AccountSID:AuthToken and the sender as whatsapp:+2547....
  7. For Meta inbound messages, copy this page's webhook URL and use the same verify token in Meta.
  8. Click Verify & save at the top of this page.

Meta and Twilio must approve or activate your WhatsApp sender before API messages can be delivered.

Set up work emails (cPanel)

This lets the system create a mailbox for each employee on approval.

  1. Sign into cPanel for the account that owns your firm domain.
  2. Copy the hostname from the browser address bar into cPanel host — for example rs3.rcnoc.com, with no https://.
  3. Leave cPanel port as 2083.
  4. Enter your cPanel login name in cPanel username — not an email address.
  5. In cPanel search for API Tokens, open Manage API Tokens, click Create, name it Sheria, and copy the token once.
  6. Paste that token into cPanel API token.
  7. Set Work email domain to your firm domain, and a mailbox quota in MB (0 means unlimited).
  8. Click Verify & save at the top of this page.

The SMTP password cannot create mailboxes — an API token is required. New staff then get first.last@yourfirm.com emailed to their personal address on approval.
